Screens are too clean. A gradient rendered in 8 bits per channel has visible steps where one shade turns into the next, and a large block of one color looks like a plastic sheet. **Noise** is a layer of random light and dark pixels laid over the surface. It breaks the steps up and gives the color some texture. Drag the slider to add grain to this card.

<NoiseDemo />

Around 6% to 10% is where it usually lands. You should have to lean in to notice the grain. Any more and the card starts to look dirty.

## Banding

This is the problem noise was made for. Both boxes below use the exact same radial gradient, from a light center into near black. The left one shows rings where the browser runs out of shades. The right one has grain on top.

<NoiseBandingDemo />

The grain does not add shades. It scatters the boundary between each pair of shades so your eye cannot find the line. Dark gradients band the most because there are fewer distinct dark values to work with, so they benefit the most.

## Grain size

The `baseFrequency` attribute controls how fine the noise is. Low values give big soft blobs. High values give the tight speckle of film grain. This demo runs the grain at a high opacity so you can see the shape change.

<NoiseFrequencyDemo />

For UI, stay between `0.6` and `1`. Below that the noise looks like clouds and starts to compete with the content. Above `1` it turns into a flat gray haze and the texture is gone.

## On real surfaces

Grain reads best on dark and saturated surfaces, where the light and dark specks both have room to show. Switch this card between flat and grain.

<NoiseSurfaceDemo />

On a white card the same grain does almost nothing, because half the specks are lighter than white and get clipped. If you want texture on a light surface, use a lower opacity and a slightly tinted background so the grain has something to push against.

## Usage

Put the filter in one SVG anywhere on the page, then reference it from an overlay. The overlay is an empty element, so it costs nothing in markup and can be dropped onto any positioned container.

<CodeBlock
  tabs={[
    {
      label: "Tailwind",
      language: "html",
      icon: "tailwind",
      code: `<svg class="absolute size-0" aria-hidden="true">
  <filter id="grain">
    <feTurbulence type="fractalNoise" baseFrequency="0.8" numOctaves="3" stitchTiles="stitch" />
    <feColorMatrix type="saturate" values="0" />
  </filter>
</svg>

<div class="relative isolate overflow-hidden rounded-2xl bg-violet-600">
  <div class="pointer-events-none absolute inset-0 opacity-[0.08] mix-blend-overlay [filter:url(#grain)]" aria-hidden="true"></div>
  <!-- content -->
</div>`,
    },
    {
      label: "CSS",
      language: "css",
      icon: "css",
      code: `.surface {
  position: relative;
  isolation: isolate;
  overflow: hidden;
}

.surface::after {
  content: "";
  position: absolute;
  inset: 0;
  filter: url(#grain);
  opacity: 0.08;
  mix-blend-mode: overlay;
  pointer-events: none;
}`,
    },
  ]}
/>

The `isolate` on the container matters. Without it, `mix-blend-mode` blends the grain with everything behind the card, including the page background, and the effect changes depending on where the card sits. With it, the grain only ever blends with the surface it belongs to.
